AI Football Coach · API 文档

给产品演示和开发对接用。日常纠错请打开 Coach UI；本页说明三个接口怎么用。

打开 Coach UI openapi.json ReDoc 经典 Swagger

GET/health

检查服务是否在跑、模型文件是否就绪。


      

    


    

      
POST/analyze

      
传入姿态 JSON（keypoints 或 pose_path），返回动作类别、置信度、几何纠错与证据帧。

      
Body JSON 示例：

      
{
  "pose_path": "fixtures/demo_pass_inside_pose.json",
  "label_id": "pass.inside"
}

      

      

      

    


    

      
POST/analyze/video

      
上传短视频 → MediaPipe 抽姿态 → 与 /analyze 相同结果。建议侧面、15 秒内。

      

        
        
        
      

      

      

      
也可用 Coach UI 里的上传区，体验更友好。
