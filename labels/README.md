# Action labels

Self-owned football technique taxonomy for youth coaching.

Draft categories (to refine with architect):

1. Passing — inside foot / driven / lofted
2. Receiving — first touch / cushion
3. Shooting — instep / side-foot / volley
4. Dribbling — close control / change of direction
5. Defending — jockey / tackle timing (optional v1)

Each label needs: id, display name (zh/en), skeleton joint focus, score dimensions (form / timing / balance).
