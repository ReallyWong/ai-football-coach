# AI Football Coach

Static GitHub Pages demo of the latest coach UI.

- Open `/` — redirects to the coach UI
- UI: `/coach-ui/` (中文 / EN, 基础技术 / 球星招牌动作)
- Sample plant-foot payload: `/fixtures/demo_analyze_response.json`
- Signature Move catalog (used when the local API is unreachable): `/labels/signature_moves.json` and `/rules/signature_rules.json`

Video analyze still needs the local API at `http://127.0.0.1:8000`. This site does not invent analyze results.
