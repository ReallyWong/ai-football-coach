# AI Football Coach

Static GitHub Pages demo of the latest coach UI.

- Open `/` — redirects to the coach UI
- UI: `/coach-ui/` (中文 / EN, Demo mode, 基础技术 / 球星招牌动作)
- Demo clips: `/fixtures/demo_analyze_response.json` (inside-foot pass) and `/fixtures/demo_shot_instep_response.json` (instep shot)
- Signature Move catalog: `/fixtures/signature_catalog.json` (fallback: `/labels/signature_moves.json` and `/rules/signature_rules.json`)

Demo mode loads those fixtures in the browser. Video upload still needs a local API with MediaPipe. This site does not invent analyze results.
