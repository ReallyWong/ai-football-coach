# 定位（中文）

## 一句话

**AI Football Coach**：用手机或训练摄像头拍下动作，自动做姿态识别与技术评分，给青少年球员即时、可执行的纠错建议——v1 不上机器人。

## 电梯稿（约 30 秒）

青少年踢球最缺的不是多看一场比赛录像，而是「这一脚哪里不对、下次怎么改」。我们把训练视频转成骨架序列，用 ST-GCN++ 识别传球、停球、射门等技术动作，再按教练规则输出纠错反馈。底层姿态与数据能力复用成熟开源积木；真正自研的是动作标签、纠错规则和 Coach 体验。对外叙事对齐 Football Match Intelligence / AI football coach：先把教练助手做成全球可演示的产品，再视情况扩展具身真机。

## 边界（说清楚我们不做什么）

- **做**：单人/小班技术动作识别、评分、纠错建议、训练复盘素材。
- **不做（v1）**：人形机器人陪练、场地对抗决策、替代持证教练的全责指导。
- **和 CV toolkit 的区别**：本仓是产品层（标签 + 规则 + Coach UI），不是又一个算法收藏夹。

## 目标用户

- 青训教练：批量看基础技术、减少重复口播。
- 家长 / 学员：训练后立刻看到「哪里偏了」。
- 内容与出海：英文主场叙事下的可演示 demo 与案例素材。
